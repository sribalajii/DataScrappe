# DataScrappe

DataScrappe is a local-first, source-backed dataset builder for research, machine learning and AI workflows.

## Current beta

- Multi-source public-data discovery
- Source URL and provenance retention
- Relevance filtering and deduplication
- CSV, Excel, JSON and TXT export
- Optional local Ollama/Gemma query planning
- No bypassing authentication, paywalls, CAPTCHAs or access controls

## Free web trial

The browser trial intentionally uses a limited public Wikipedia adapter and returns up to 10 records. The native desktop beta contains the broader acquisition pipeline.

## Automated builds

GitHub Actions is configured to build beta packages for Windows, Linux and macOS, publish a rolling `beta-latest` prerelease, and generate real PyQt screenshots plus a short MP4 walkthrough.

## Responsible use

Use DataScrappe only on information you are legally permitted to access. Respect website terms, robots policies, privacy rights, copyright and applicable law.
